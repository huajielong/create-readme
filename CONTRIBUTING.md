# Contributing

Open an issue or a pull request. Keep changes small and testable.

- Behavior changes need an eval in `evals/evals.json`.
- Keep `SKILL.md` concise; put long guidance in `references/`.
- Do not add secrets, personal paths, model weights, or generated logs.
- The audit script must stay read-only.
- By contributing, you agree to license your work under the MIT License.
